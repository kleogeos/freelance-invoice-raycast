# Freelance Invoice

Generate a clean, printable HTML invoice from a quick Raycast form — no account, no cloud upload, nothing leaves your machine.

## How it works

Run **Create Invoice**, fill in:

- Invoice number, from/to, date, due date
- Items — one per line as `description, qty, rate`
- Optional tax rate and notes

Submitting writes the invoice as an HTML file to your temp folder and opens it in your default browser, ready to print to PDF or send to a client.
